# شؤون الموظفين — Daftari UI

تطبيق Flutter (واجهة عربية RTL) لشؤون الموظفين في المنطقة الحرة بمصراتة.

تسجيل الدخول مربوط بـ Nest API المحلي. باقي الشاشات ما زالت ببيانات ثابتة إلى حين ربطها.

## التشغيل محلياً

1. شغّل الـ API أولاً على `http://127.0.0.1:3000/api`
2. ثم:

```bash
flutter pub get
flutter run -d chrome --web-port=43123
```

الدخول عبر:

`POST http://127.0.0.1:3000/api/v1/auth/login`

Body:

```json
{ "employeeNumber": "10234", "password": "..." }
```

تأكد أن CORS يسمح بأصل تطبيق Flutter Web.

## ما هو جاهز

- تسجيل الدخول الحقيقي عبر Nest Auth API (`/api/v1/auth/login`) مع حفظ التوكنات
- الصفحة الرئيسية للموظف العادي (من `index.php`) بتوزيع أقسام أوضح:
  - ترحيب
  - أرصدة الإجازات + رصيد الأذونات
  - تقديم طلب جديد (يسأل: إجازة أم إذن؟)
  - روابط تهمك
  - ملخص شهري
  - طلبات بفلتر (معلّقة / مقبولة / مرفوضة)
- تقديم طلب إذن (من `makeRequest.php`) بواجهة مضغوطة + ضوابط قابلة للطي
- تقديم طلب إجازة (من `Taking_a_day_off.php`) بنفس أسلوب الأذونات
- مركز اللوائح والمخالفات (من `regulations-modal.php` و `single-reg-modal.php`)

## ملاحظة أندرويد

تطوير الواجهة يتم عبر Chrome حالياً. بناء APK يحتاج إعداد NDK صحيح على الجهاز المحلي.
